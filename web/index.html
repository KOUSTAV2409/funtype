Keyboard Cheatsheet

Key Binding Action / Function Scope

3 / F3 Switch to Speed Sprint (15s/30s/60s) Anywhere

F4 Cycle aesthetic themes (Catppuccin, Tokyo Night, Nord...) Any Mode
Ctrl + T Cycle duration: 15s / 30s / 60s / Free Fall Sprint & Shredder
Ctrl + M Targeted drill generator for your weakest keys Speed Sprint
Ctrl + R / F5 Instant Reset / Restart active test Any Mode
